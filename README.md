## ⚡ About The Project

**Aurix — Autonomous AI Lab** is an experimental, immersive web experience designed around the idea of **autonomous intelligence**.

Unlike a conventional static portfolio or dashboard, Aurix focuses on creating a more interactive way to present AI concepts through:

- 🧠 Artificial Intelligence
- 🤖 Autonomous Systems
- 🌌 3D Web Experiences
- 🖱️ Interactive Scrolling
- 🎞️ Motion-Based Interfaces
- 🌐 Immersive Digital Environments
- ⚡ Modern Web Technologies

The project combines **React, Three.js, Motion, Tailwind CSS, and modern TypeScript-based development** to create an interactive interface where the visual experience itself becomes part of the product.

---

# ⭐ Why Aurix Is Different

Aurix is not designed as a traditional website with a hero section, cards, and a collection of static sections.

The core idea is to make the website behave more like an **interactive digital environment**.

### 🧊 First 3D Scrolling Web Experience

> **Aurix is my first dedicated 3D scrolling website project.**

The project explores how scrolling can become an interaction mechanism instead of simply being a way to move between sections.

The experience combines:

```text
User Interaction
       │
       ▼
Scroll Movement
       │
       ▼
Motion & Transitions
       │
       ▼
3D Scene Interaction
       │
       ▼
Immersive AI Experience
```

This project represents my move from building conventional web applications toward creating **interactive, visually driven digital products**.

# 🎨 3D Experience

The project uses **Three.js** to introduce real-time 3D capabilities into the browser.

Three.js provides the foundation for:

- 3D scene rendering
- Interactive visual environments
- WebGL-based graphics
- Spatial visual elements
- Immersive interface components

Instead of treating 3D as decoration, Aurix uses it as part of the overall interaction model.

---

# 🖱️ Scroll-Driven Interaction

One of the defining characteristics of Aurix is its **scroll-based interaction model**.

Instead of:

```text
Scroll → Read → Scroll → Read
```

the experience is designed around:

```text
Scroll
  ↓
Scene Transformation
  ↓
Motion
  ↓
Visual Feedback
  ↓
New Content State
```

This approach allows the user to progressively move through the experience while the interface responds dynamically.

---

# 🎞️ Motion & Animation

Aurix uses modern motion techniques to create a smoother transition between different states of the experience.

The motion layer is responsible for creating:

- Smooth transitions
- Entrance animations
- Interactive movement
- Scroll-linked effects
- State transitions
- Visual feedback

The project uses **Motion** as part of its modern interaction stack.

---

# 🛠️ Local Development

## 1. Clone the Repository

```bash
git clone https://github.com/Lalithkrish06/autonomous-ai-lab.git
```

## 2. Move Into the Project

```bash
cd autonomous-ai-lab
```

## 3. Install Dependencies

```bash
npm install
```

or, if using Bun:

```bash
bun install
```

## 4. Start Development Server

```bash
npm run dev
```

or:

```bash
bun run dev
```

The Vite development server runs on port `3000` according to the project's current configuration.

---

# 🏗️ Production Build

Create a production build with:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

TypeScript validation:

```bash
npm run lint
```

These commands are defined in the current project configuration.
